# cap30-calculator
30-day mortality risk calculator for adults hospitalized with pneumonia (Model D: Extended × XGBoost, MICE m = 10 + OOF Platt calibration). Research use only.

Version 3.0 (model v7): 31 predictors available at admission; altered mental status (GCS < 15) entered as yes/no; CRP removed. Temporal validation AUC 0.827.
